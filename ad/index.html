Windows 账号同步

只读同步账号和启用状态，保留已有绑定。账号创建、改密与启停在 Windows 中完成，不写回账号源。移出同步范围不等同于撤销 PBIRS 中已有授权。

目录与报表授权

目录绑定覆盖下级报表；单报表绑定独立保留。取消直接绑定不会撤销 Windows 组授予的权限。

行级权限与规则

角色绑定写入 PBIRS。表名与 DAX 来自只读模型采集；未读取或过期会明确标记。多个角色的可见数据通常取并集，Windows 组角色独立生效。
